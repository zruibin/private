## 1.FFT(快速傅里叶变换)

### 1.前置技能

复数:  

基本表示法及性质:

<span class="LaTex" alt="LaTex">$$i=\sqrt{-1}$$</span>

<span class="LaTex" alt="LaTex">$$i$$</span>是虚数单位

#### 1.坐标(代数)形式：

<span class="LaTex" alt="LaTex">$$z=a+bi$$</span>

当b为0是z为实数，当a为0时为纯虚数

注:复数包括实数和虚数，虚数下有纯虚数

**虚数z对应了复平面上的一点(a,b)**

运算法则： 

设复数<span class="LaTex" alt="LaTex">$$z_1,z_2,z_1=a+bi,z_2=c+di$$</span>

加法:<span class="LaTex" alt="LaTex">$$z_1+z_2=(a+c)+(b+d)i$$</span>  
减法:<span class="LaTex" alt="LaTex">$$z_1-z_2=(a-c)+(b-d)i$$</span>  
乘法:<span class="LaTex" alt="LaTex">$$z_1*z_2=(ac-bd)+(bc+ad)i$$</span>  
除法:<span class="LaTex" alt="LaTex">$$\dfrac{z_1}{z_2}=\dfrac{(ac+bd)+(bc-ad)i}{(c^2+d^2)}$$</span>

#### 2.三角形式

<span class="LaTex" alt="LaTex">$$z=r(cos \theta+isin\theta)$$</span>

<span class="LaTex" alt="LaTex">$$\theta$$</span>是复数<span class="LaTex" alt="LaTex">$$z$$</span>的幅角,<span class="LaTex" alt="LaTex">$$r$$</span>是该复数的模长

这种形式下的乘法和除法运算更方便，通过和角公式，对于复数<span class="LaTex" alt="LaTex">$$z_1=r_1(cos\theta_1+isin\theta_1),z_2=r_2(cos\theta_2+isin\theta_2)$$</span>
那么：

<span class="LaTex" alt="LaTex">$$
z_1z_2=r_1r_2(cos(\theta_1+\theta_2)+isin(\theta_1+\theta_2))\\
\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}(cos(\theta_1-\theta_2)+isin(\theta_1-\theta_2))\\
$$</span>

几何意义:相当于把该复数 _拉长/缩短_ 到另一个复数模长 _倍/分之一_ ,然后 _顺时针/逆时针_ 旋转另一个复数的幅角大小的角度

**于是有了如下非常有用的公式:**

<span class="LaTex" alt="LaTex">$$z^n=(r(cos\theta+isin\theta))^n=r^n(cos\ n\theta+isin\ n\theta)$$</span>

#### 3.指数形式

<span class="LaTex" alt="LaTex">$$z=re^{i\theta}$$</span>

于是我们知道了:<span class="LaTex" alt="LaTex">$$e^{i\theta}=cos\theta+isin\theta$$</span>

可以发现:

<span class="LaTex" alt="LaTex">$$e^{i\pi}=-1$$</span> 

<s>(优美)</s>

这个算乘除法就更好算了:  

有:

<span class="LaTex" alt="LaTex">$$
z_1z_2=r_1r_2e^{i(\theta_1+\theta_2)}\\
\dfrac{z_1}{z_2}=\dfrac{r_1}{r_2}e^{i(\theta)}\\
$$</span>

上面的那个公式就可写成这样：

<span class="LaTex" alt="LaTex">$$z^n=r^ne^{i(n\theta)}$$</span>

#### 4.单位复数根

学FFT最重要的就这个了吧  

设有如下方程:

<span class="LaTex" alt="LaTex">$$z^n=1$$</span>

这方程的复数根<span class="LaTex" alt="LaTex">$$z$$</span>为<span class="LaTex" alt="LaTex">$$n$$</span>次单位根,通常记为<span class="LaTex" alt="LaTex">$$w$$</span>  
这样的根<span class="LaTex" alt="LaTex">$$w$$</span>有n个，也就是说<span class="LaTex" alt="LaTex">$$n$$</span>次单位根有<span class="LaTex" alt="LaTex">$$n$$</span>个,记为<span class="LaTex" alt="LaTex">$$w_k (k=0,1,2,\dots n-1)$$</span>  
其中:

<span class="LaTex" alt="LaTex">$$w_k=cos\frac{2k\pi}{n}+isin\frac{2k\pi}{n}=e^{\frac{2\pi ki}{n}}$$</span>

不难发现其实<span class="LaTex" alt="LaTex">$$n$$</span>次单位复数根就是把复平面上的单位圆 <span class="LaTex" alt="LaTex">$$n$$</span> 等分后的那些<span class="LaTex" alt="LaTex">$$n$$</span>等分点

一些次数单位的单位根举例:

1次单位根: <span class="LaTex" alt="LaTex">$$1$$</span>

2次单位根: <span class="LaTex" alt="LaTex">$$1,-1$$</span>  

3次单位根: <span class="LaTex" alt="LaTex">$$1,\frac{-1+\sqrt{3}i}{2},\frac{-1-\sqrt{3}i}{2}$$</span>  
<span class="LaTex" alt="LaTex">$$\dots$4</span>  

其实就是个解二元n次方程

可以发现1是任意次的单位复数根，-1是任意偶数次单位复数根

某些引理:

**1.消去引理**

<span class="LaTex" alt="LaTex">$$w_{dn}^{dk}=w_n^k$$</span>

把复数的指数形式带进去就可以了  

说人话就是不同次数的单位根可以互相转化

**2.折半引理**  

假设<span class="LaTex" alt="LaTex">$$n$$</span>是大于0的偶数:

<span class="LaTex" alt="LaTex">$$(w_n^{k+\frac{n}{2}})^2=w_n^{2k+n}=w_n^{2k}*w_n^n=(w_n^{k})^2$$</span>

说人话就是n次单位复数根的前后两半平方后是对应相等的

**3.求和引理**

对于大于1的整数n和小于等于n的整数k有:

<span class="LaTex" alt="LaTex">$$\sum_{i=0}^{n-1}(w_n^k)^i=0$$</span>

这就是个等比数列求和

### 2.步入正题

常规的一个最高次数为n-1的多项式的表示形式是系数表示法,如:

<span class="LaTex" alt="LaTex">$$A(x)=a_0+a_1x+a_2x^2+a_3x^3+\dots+a_{n-1}x^{n-1}$$</span>

一共有n项  

按照朴素的多项式乘法(卷积),就是每一项两两相乘，复杂度为<span class="LaTex" alt="LaTex">$$O(n^2)$$</span>

如果我们把多项式看成一个函数，我们取图像上的n个点来表示这个函数也即该多项式，这样的表示法叫做点值表示法

对于两个n-1次多项式,由于我们最后卷积出来的多项式是2n-2次的,如果我们知道了卷积后的多项式函数图像上的至少2n-1个点，那么我们就可以确定这个多项式了

所以有如下想法：  

现在原来的两个多项式上选取好x值相同的点(个数为原来两多项式次数的和加1)，用<span class="LaTex" alt="LaTex">$$O(n)$$</span>的时间将选的点的y值相乘，得到的值用某种方法<s>(待定系数法)</s>转化为多项式系数的形式

如果选取的x都是n次单位复数根的k次方，那么以上两个过程就是<span class="LaTex" alt="LaTex">$$DFT$$</span>和<span class="LaTex" alt="LaTex">$$IDFT$$</span>了

#### 1.DFT

离散傅里叶变换：  

对于<span class="LaTex" alt="LaTex">$$k\in [0,n-1],$$</span>和n-1次多项式<span class="LaTex" alt="LaTex">$$A(x),$$</span>定义:

<span class="LaTex" alt="LaTex">$$y_k=A(w_n^k)=\sum_{i=0}^{n-1}a_i(w_n^k)^i$$</span>

这个叫做离散傅里叶变换，记做<span class="LaTex" alt="LaTex">$$y=DFT_n(a)$$</span>

朴素求<span class="LaTex" alt="LaTex">$$DFT$$</span>,是<span class="LaTex" alt="LaTex">$$O(n^2)$$</span>的

#### 2.IDFT

逆离散傅里叶变换:

就是<span class="LaTex" alt="LaTex">$$DFT$$</span>的逆运算，用于求出多项式的系数a，记为<span class="LaTex" alt="LaTex">$$DFT^{-1}$$</span>

本人太弱不会证，丢个式子:

<span class="LaTex" alt="LaTex">$$a_k=\dfrac{1}{n}\sum_{i=0}^{n-1}y_i(w_n^{-k})^i$$</span>

由于写的时候系数表达式和点值表达式是共用的数组，所以写起来和<span class="LaTex" alt="LaTex">$$DFT$$</span>没什么差别

#### 3.FFT

快速傅里叶变换:

是一种快速求出<span class="LaTex" alt="LaTex">$$DFT$$</span>和<span class="LaTex" alt="LaTex">$$DFT^{-1}$$</span>的算法，利用了单位复数根的优良性质

我们先列出朴素求<span class="LaTex" alt="LaTex">$$DFT$$</span>的步骤,为了方便这里先不妨假设多项式次数为2的幂:  

1. 求出n次单位复数根的幂:<span class="LaTex" alt="LaTex">$$w_n^0,w_n^1,w_n^2.....w_n^{n-1}$$</span>  

2. 代入多项式<span class="LaTex" alt="LaTex">$$A(x)$$</span>,求得以下式子:

<span class="LaTex" alt="LaTex">$$
A(w_n^0)=a_0+a_1w_n^0+a_2(w_n^0)^2+a_3(w_n^0)^3+\dots a_{n-1}(w_n^0)^{n-1}
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_n^1)=a_0+a_1w_n^1+a_2(w_n^1)^2+a_3(w_n^1)^3+\dots a_{n-1}(w_n^1)^{n-1}
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_n^2)=a_0+a_1w_n^2+a_2(w_n^2)^2+a_3(w_n^2)^3+\dots a_{n-1}(w_n^2)^{n-1}
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_n^3)=a_0+a_1w_n^3+a_2(w_n^3)^2+a_3(w_n^3)^3+\dots a_{n-1}(w_n^3)^{n-1}
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots\dots
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_n^{n-1})=a_0+a_1w_n^{n-1}+a_2(w_n^{n-1})^2+a_3(w_n^{n-1})^3+\dots a_{n-1}(w_n^{n-1})^{n-1}\\
$$</span>

根据折半引理,我们可以发现:

对于一个<span class="LaTex" alt="LaTex">$$A(w_n^k)$$</span>,<span class="LaTex" alt="LaTex">$$(k<\frac{n}{2})$$</span>它的每一个偶数次方项与<span class="LaTex" alt="LaTex">$$A(w_n^{k+\frac{n}{2}})$$</span>是对应相同的

以n=4的情况来考虑:  

就是要求:

<span class="LaTex" alt="LaTex">$$
A(w_4^0)=a_0+a_1w_4^0+a_2(w_4^0)^2+a_3(w_4^0)^3
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^1)=a_0+a_1w_4^1+a_2(w_4^1)^2+a_3(w_4^1)^3
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^2)=a_0+a_1w_4^2+a_2(w_4^2)^2+a_3(w_4^2)^3
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^3)=a_0+a_1w_4^3+a_2(w_4^3)^2+a_3(w_4^3)^3\\
$$</span>

把每一个多项式的偶数次数项的系数提出来组成的多项式记为<span class="LaTex" alt="LaTex">$$A^{[0]}(x)$$</span>,奇数项记为<span class="LaTex" alt="LaTex">$$A^{[1]}(x)$$</span>

那么有:

<span class="LaTex" alt="LaTex">$$
A^{[0]}((w_4^0)^2)=A^{[0]}((w_4^2)^2)\\
a_0=a_0\\
a_1(w_4^0)^2=a_1(w_4^2)^2\\
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]}((w_4^1)^2)=A^{[0]}((w_4^3)^2)\\
a_0=a_0\\
a_1(w_4^1)^2=a_1(w_4^3)^2\\
\dots\\
$$</span>

奇数项就没有这么优美的性质,但是我们可以提出来一个x使得它变成偶数项  

所以我们现在考虑把一个多项式奇偶分组:  

显然会有如下结论:

<span class="LaTex" alt="LaTex">$$A(x)=A^{[0]}(x^2)+xA^{[1]}(x^2)$$</span>

就是

<span class="LaTex" alt="LaTex">$$
A(w_4^0)=A^{[0]}((w_4^0)^2)+w_4^0A^{[1]}((w_4^0)^2)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^1)=A^{[0]}((w_4^1)^2)+w_4^1A^{[1]}((w_4^1)^2)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^2)=A^{[0]}((w_4^2)^2)+w_4^2A^{[1]}((w_4^2)^2)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^3)=A^{[0]}((w_4^3)^2)+w_4^3A^{[1]}((w_4^3)^2)
$$</span>

折半引理化简一下:

<span class="LaTex" alt="LaTex">$$
A(w_4^0)=A^{[0]}(w_2^0)+w_4^0A^{[1]}(w_2^0)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^1)=A^{[0]}(w_2^1)+w_4^1A^{[1]}(w_2^1)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^2)=A^{[0]}(w_2^0)+w_4^2A^{[1]}(w_2^0)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A(w_4^3)=A^{[0]}(w_2^1)+w_4^3A^{[1]}(w_2^1)
$$</span>

那么我们知道如果把上面的分成两半,**根据折半引理:前后两半对应的只有后面要乘上的单位复数根不一样**,所以其实我们已经把问题的规模缩小了一半了,因为我们只
需求解如下东西:

<span class="LaTex" alt="LaTex">$$A
A^{[0]}(w_2^0)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[1]}(w_2^0)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]}(w_2^1)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[1]}(w_2^1)
$$</span>

<span class="LaTex" alt="LaTex">$$P.S.$$</span>  

其实我们还可以发现:

<span class="LaTex" alt="LaTex">$$
因为ω_n^\frac{n}{2}=e^{k\pi i}=coskπ+isinkπ=−1\\
所以A(ω^{k+\frac{n}{2}}_n)=A^{[0]}(ω^k_\frac{n}{2})−ω^k_nA^{[1]}(ω^k_\frac{n}{2})\\
$$</span>

**所以说其实只是后面的系数的符号不一样**

再来观察一下现在要求的东西,可以发现如果把整个子问题也进行奇偶分组的话,每一组其实要求的是长度为原来一半的<span class="LaTex" alt="LaTex">$$DFT$$</span>,如果采用递归进行处理,那么递归分组一次之后  

要求的子问题是:

<span class="LaTex" alt="LaTex">$$
A^{[0]}(w_2^0)=a_0+a_2w_2^0
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]}(w_2^1)=a_0+a_2w_2^1
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[1]}(w_2^0)=a_1+a_3w_2^0
$$</span>
<br/>

<span class="LaTex" alt="LaTex">$$
A^{[1]}(w_2^1)=a_1+a_3w_2^1
$$</span>

于是我们只要计算这4个子问题原<span class="LaTex" alt="LaTex">$$DFT$$</span>的两边就都可以直接算出来了  

并且对于该子问题,我们也只需求解<span class="LaTex" alt="LaTex">$$A^{[0]}(w_2^0)和A^{[1]}(w_2^0)$$</span>,另一半也是和上面的一样由这一半推出,因为这是一个长度

为原来一半的<span class="LaTex" alt="LaTex">$$DFT$$</span>

我们先看看递归版应该怎么实现:  

1. 不停将要求的<span class="LaTex" alt="LaTex">$$DFT$$</span>进行奇偶分组并递归下去  
2. 如果只有一个元素,显然这时<span class="LaTex" alt="LaTex">$$x=w_1^0=1$$</span>,直接返回当前的系数就可以了  
3. 合并答案:  

把每层要求的东西写出来:

<span class="LaTex" alt="LaTex">$$
A(w_4^0)\;\;\;\;A(w_4^1)\;\;\;\;A(w_4^2)\;\;\;\;A(w_4^3)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]}(w_2^0)\;\;A^{[0]}(w_2^1)\;\;A^{[1]}(w_2^0)\;\;A^{[1]}(w_2^1)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
a_0\;\;\;\;\;\;\;\;\;\;\;a_2\;\;\;\;\;\;\;\;\;\;\;\;\;a_1\;\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_3
$$</span>

根据上面的公式就很容易知道每个元素是由下一层的哪一个得来的了,这很像个蝴蝶,于是被成为蝴蝶操作

还没有理解的话可以看看8的情况,建议自己手画一下,标出贡献来源,这样就很容易理解了

<span class="LaTex" alt="LaTex">$$
A(w_8^0)\;\;\;\;\;\;A(w_8^1)\;\;\;\;\;\;A(w_8^2)\;\;\;\;\;\;A(w_8^3)\;\;\;\;\;\;A(w_8^4)\;\;\;\;\;\;A(w_8^5)\;\;\;\;\;\;A(w_8^6)\;\;\;\;\;\;A(w_8^7)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]}(w_4^0)\;\;\;\;\;\;A^{[0]}(w_4^1)\;\;\;\;\;\;A^{[0]}(w_4^2)\;\;\;\;\;\;A^{[0]}(w_4^3)\;\;\;\;\;\;A^{[1]}(w_4^0)\;\;\;\;\;\;A^{[1]}(w_4^1)\;\;\;\;\;\;A^{[1]}(w_4^2)\;\;\;\;\;\;A^{[1]}(w_4^3)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
A^{[0]^{[0]}}(w_2^0)\;\;\;\;A^{[0]^{[0]}}(w_2^1)\;\;\;\;A^{[0]^{[1]}}(w_2^0)\;\;\;\;A^{[0]^{[1]}}(w_2^1)\;\;\;\;A^{[1]^{[0]}}(w_2^0)\;\;\;\;A^{[1]^{[0]}}(w_2^1)\;\;\;\;A^{[1]^{[1]}}(w_2^0)\;\;\;\;A^{[1]^{[1]}}(w_2^1)
$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$
a_0\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_4\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_2\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_6\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_1\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_5\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_3\;\;\;\;\;\;\;\;\;\;\;\;\;\;a_7
$$</span>

从下往上蝴蝶的跨度不断增大,倒数第2层就是相邻的两个元素宽度半径为1,然后往上不断倍增, 每一次只是改变两个位置对应的数,所以其实也可以写成非递归的  

但是我们需要最后分组后的最下面一层其实每个数最后在的位置是他的二进制反序数,所以是一个Rader排序(二进制反转),这个并不是非常重要,记一下就差不多了

贴个非递归的板子:

```cpp
#include<iostream>
#include<cstdio>
#include<cstring>
#include<cmath>
#include<algorithm>
#include<cstdlib>
using namespace std;

inline int read()
{
	int x=0;char ch=getchar();int t=1;
	for(;ch>'9'||ch<'0';ch=getchar()) if(ch=='-') t=-1;
	for(;ch>='0'&&ch<='9';ch=getchar()) x=(x<<1)+(x<<3)+(ch-48);
	return x*t;
}

typedef long long ll;
typedef double db;
const db PI=acos(-1);

struct Complex{//手写复数
	db x,y;
	Complex(db x1=0.0,db y1=0.0){x=x1,y=y1;}
	inline Complex operator +(const Complex &b)const{return Complex(x+b.x,y+b.y);}
	inline Complex operator -(const Complex &b)const{return Complex(x-b.x,y-b.y);}
	inline Complex operator *(const Complex &b)const{return Complex(x*b.x-y*b.y,x*b.y+y*b.x);}
	inline void init(){x=read();}
	inline void out(){printf("%lf %lf\n",x,y);}
};

typedef Complex C;
const int N=4e6+10;
int r[N],l;int n,m;
C a[N],b[N];

inline void FFT(C *P,int f)
{
	for(register int i=0;i<n;++i) if(i<r[i]) swap(P[i],P[r[i]]);
	for(register int i=1;i<n;i<<=1){//枚举每一层蝴蝶操作的跨度
		C W(cos(PI/i),f*sin(PI/i));//同层所需要的单位根是相同的(是蝴蝶操作直径次单位根)
		for(register int p=i<<1,j=0;j<n;j+=p){
	//两倍当前蝴蝶操作半径为一组(这里是多项式系数奇偶分组后的组数)
			C w(1,0);
			for(register int k=0;k<i;++k,w=w*W){
	//每组内有蝴蝶操作直径个子DFT,但是蝴蝶操作每次处理两个,只要枚举到半径的长度
				C X=P[j+k],Y=w*P[j+k+i];
				P[j+k]=X+Y,P[j+k+i]=X-Y;
			}
		}
	}
}

int main()
{
	n=read();m=read();
	for(register int i=0;i<=n;++i) a[i].init();
	for(register int i=0;i<=m;++i) b[i].init();
	m+=n;l=0;
	for(n=1;n<=m;n<<=1) ++l;//补成2的幂 
	for(register int i=1;i<n;++i) r[i]=(r[i>>1]>>1)|((i&1)<<l-1);//Rader
	FFT(a,1); FFT(b,1);
	for(register int i=0;i<n;++i) a[i]=a[i]*b[i];
	FFT(a,-1);
	for(register int i=0;i<=m;++i) printf("%d ",(int)(a[i].x/n+0.5));//IDFT最后除n
	return 0;
}
```

2.注意蝴蝶操作的式子不要记错, Y 要乘上单位复数根!

## 2.NTT(快速数论变换)

### 1.NTT模数NTT

在模意义下有如下结论:

<span class="LaTex" alt="LaTex">$$w_n=e^{\frac{2\pi i\theta}{n}}=g^{\frac{p-1}{n}}\ (mod\ p)$$</span>

其中<span class="LaTex" alt="LaTex">$$g$$</span>是<span class="LaTex" alt="LaTex">$$p$$</span>的原根,然后就直接把这个代换进FFT模板就可以了,加上模意义下的基本操作

常用NTT模数以及其原根:

<span class="LaTex" alt="LaTex">$$998244353=119*2^{23}+1\;\ \ ------3$$</span>
<br/>
<span class="LaTex" alt="LaTex">$$1004535809=479*2^{21}+1\ ------3$$</span>

注意,虽然

<span class="LaTex" alt="LaTex">$$1000000007$$</span>的原根是<span class="LaTex" alt="LaTex">$$5$$</span> 
但是我们必须要保证 NTT 的时候数组的长度 <span class="LaTex" alt="LaTex">$$N$$</span> 始终是 <span class="LaTex" alt="LaTex">$$(P-1)$$</span> 的因数,所以 <span class="LaTex" alt="LaTex">$$10^9+7$$</span> 并不能用来直接做<span class="LaTex" alt="LaTex">$$NTT$$</span> 模数<span class="LaTex" alt="LaTex">$$!!$$</span>

主体代码:

```cpp    
inline int fpow(int x,int k){int ret=1;for(;k;k>>=1,x=1ll*x*x%mod) if(k&1) ret=1ll*ret*x%mod;return ret;}
inline void Mod(int&x){if(x>=mod) x-=mod;else if(x<0) x+=mod;return;}
const int mod=998244353;
const int phi=998244352;
const int G=3;

inline void NTT(int *A,int n,int f)
{
	for(int i=1;i<n;++i) if(rader[i]>i) swap(A[i],A[rader[i]]);
	for(int i=1;i<n;i<<=1){
		int W=fpow(G,phi/(i<<1));
		if(f==-1) W=fpow(W,mod-2);
		for(int p=i<<1,j=0;j<n;j+=p){
			int w=1;
			for(int k=0;k<i;++k,w=1ll*w*W%mod){
				int X=A[j|k],Y=1ll*w*A[j|k|i]%mod;
				Mod(A[j|k]=X+Y);Mod(A[j|k|i]=X-Y);
			}
		}
	}
	if(f==-1) for(int i=0;i<n;++i) A[i]=1ll*A[i]*inv[n]%mod;
	return;
}
```

> 注意事项  
1.如果确定计算结果不会超过你的 NTT 模数,那么可以用 NTT 来代替 FFT 进行运算

### 2.任意模数NTT

如果真的就是让你用 <span class="LaTex" alt="LaTex">$$10^9+7$$</span> 等模数来<span class="LaTex" alt="LaTex">$$NTT$$</span>,怎么办 
那么就要用 <span class="LaTex" alt="LaTex">$$MTT$$</span>(任意模数<span class="LaTex" alt="LaTex">$NTT$</span>)了

这里用的是拆系数的方法  

假设模数为 <span class="LaTex" alt="LaTex">$$P$$</span>,两个多项式分别为 <span class="LaTex" alt="LaTex">$$A(x),B(x)$$</span> 
我们取 <span class="LaTex" alt="LaTex">$$M=\sqrt P$$</span>,并将多项式的系数<span class="LaTex" alt="LaTex">$$K$$</span>分为 <span class="LaTex" alt="LaTex">$$K/M,K\mod M$$</span> 两部分,那么可以把每一个多项式拆分为两个系数都不超过<span class="LaTex" alt="LaTex">$$M$$</span>的多项式,分别<span class="LaTex" alt="LaTex">$$DFT和IDFT$$</span>,最后还原出系数并对原模数取模即可,这样的话最后的系数最大可能达到 <span class="LaTex" alt="LaTex">$$nP$$</span>的级别,要确保<span class="LaTex" alt="LaTex">$$long\ long$$</span>能存下

主体代码:

```cpp
inline void MTT(int n,int *A,int *B,int *C)
{
	for(int i=0;i<n;++i) {A1[i]=Co(A[i]/P,0);A2[i]=Co(A[i]%P,0);B1[i]=Co(B[i]/P,0);B2[i]=Co(B[i]%P,0);}
	
	for(int i=1;i<n;i<<=1)
		for(int k=0;k<i;++k)
			w[n/i*k]=Co(cos(1.00*k*PI/i),sin(1.00*k*PI/i));

	FFT(n,A1,1);FFT(n,A2,1);FFT(n,B1,1);FFT(n,B2,1);
	
	for(int i=0;i<n;++i){
		Co X=A1[i]*B1[i],Y=A2[i]*B1[i]+A1[i]*B2[i],Z=A2[i]*B2[i];
		A1[i]=X,A2[i]=Y,B1[i]=Z;
	}
	
	FFT(n,A1,-1);FFT(n,A2,-1);FFT(n,B1,-1);
	
	int P2=1ll*P*P%mod;
	
	for(int i=0;i<n;++i){
		ll X=(ll)(A1[i].x+0.5)%mod,Y=(ll)(A2[i].x+0.5)%mod,Z=(ll)(B1[i].x+0.5)%mod;
		C[i]=0;C[i]=X*P2%mod;upd(C[i],Y*P%mod);upd(C[i],Z);
	}
	
	return;
}
```

## 3.多项式的一些基本操作

### 1.多项式求逆

求<span class="LaTex" alt="LaTex">$$G(X)$$</span>使<span class="LaTex" alt="LaTex">$$F(x)G(x)\equiv 1\ (mod\ x^n)$$</span> 

其含义是无论当<span class="LaTex" alt="LaTex">$$x$$</span>取何值时,该式子总成立,那么如果该多项式有逆,那么他的逆是唯一的

采用倍增法,假设我们已经知道了 <span class="LaTex" alt="LaTex">$$F(x)H(x)\equiv 1\ (mod\ x^{\lceil \frac{n}{2} \rceil})$$</span>  

那么因为显然有:

<span class="LaTex" alt="LaTex">$$F(x)G(x)\equiv 1\ (mod\ x^{\lceil \frac{n}{2} \rceil})$$</span>

上下相减并除掉 <span class="LaTex" alt="LaTex">$$F(x)$$</span>

<span class="LaTex" alt="LaTex">$$G(x)-H(x)\equiv 0\ (mod\ x^{\lceil \frac{n}{2} \rceil})$$</span>

记<span class="LaTex" alt="LaTex">$$D(x)=G(X)-H(x)$$</span>那么必须满足<span class="LaTex" alt="LaTex">$$D(x)$$</span>的<span class="LaTex" alt="LaTex">$$0\sim {\lceil\frac{n}{2}\rceil-1}$$</span>次方项的系数均为 0  

把<span class="LaTex" alt="LaTex">$$D(x)$$</span>平方,那么显然小于 <span class="LaTex" alt="LaTex">$$n$$</span> 次方项的系数均为 0, 因为其中必定含有一个次数小于 <span class="LaTex" alt="LaTex">$$\lceil \frac{n}{2}\rceil-1$$</span>的项,那么显然会有

<span class="LaTex" alt="LaTex">$$D^2(x)\equiv 0\ (mod\ x^n)$$</span>

之后回代并在两边乘上<span class="LaTex" alt="LaTex">$$F(x)$$</span>,变形可得:

<span class="LaTex" alt="LaTex">$$G(x)\equiv 2*H(x)-F(x)*H^2(x)\ (mod\ x^n)$$</span>

所以不断递归就行了,如果模数不是 NTT 模数,那么需要 MTT 边界就是当 n=1 的时候直接求逆元

主体代码:

```cpp
void Poly_inv(int n){
	if(n==1){return (void)(B[0]=fpow(A[0],mod-2));}
	Poly_inv((n+1)>>1);
	int m=n<<1;
	int len,up;for(len=1,up=-1;len<=m;len<<=1,++up);
	rader[0]=0;for(int i=1;i<len;++i) rader[i]=(rader[i>>1]>>1)|((i&1)<<up);
	for(int i=0;i<n;++i) C[i]=A[i];for(int i=n;i<len;++i) C[i]=0;
	NTT(len,C,1);NTT(len,B,1);
	for(int i=0;i<len;++i) B[i]=(2ll*B[i]-1ll*C[i]*B[i]%mod*B[i]%mod+mod)%mod;
	NTT(len,B,-1);
	for(int i=n;i<len;++i) B[i]=0;
	return;
}
```

### 2.多项式除法&取模

求解:  

给定次数分别为<span class="LaTex" alt="LaTex">$$n,m$$</span>的多项式<span class="LaTex" alt="LaTex">$$F(x),G(x)$$</span>,求出次数为 <span class="LaTex" alt="LaTex">$$n-m$$</span>的多项式<span class="LaTex" alt="LaTex">$$Q(x)$$</span>和次数小于<span class="LaTex" alt="LaTex">$$m$$</span>的多项式<span class="LaTex" alt="LaTex">$$R(x)$$</span>,使得:

<span class="LaTex" alt="LaTex">$$F(x)=Q(x)*G(x)+R(x)$$</span>

可以发现<span class="LaTex" alt="LaTex">$$Q(x)$$</span>即为多项式除法的商,而<span class="LaTex" alt="LaTex">$$R(x)$$</span>为余数

首先你可能会想,除法不就是乘上多项式的逆吗,所以直接求逆即可。  
但是你会发现好像这个东西没办法下手，因为有次数限制和余数,并且这个不是多项式求逆的式子的形式。  
所以我们必须要找到一种方法使得能够把式子转化为能和多项式求逆搭上边的。

那么做法就是,定义<span class="LaTex" alt="LaTex">$$F_R(x)=x^nF(\dfrac{1}{x})$$</span>,这个显然就是把 <span class="LaTex" alt="LaTex">$$F(x)$$</span> 的系数翻转了一下。  

那么我们把原式中的<span class="LaTex" alt="LaTex">$$x$$</span>用 <span class="LaTex" alt="LaTex">$$\dfrac{1}{x}$$</span> 来替换,并且两边乘上一个<span class="LaTex" alt="LaTex">$$x^n$$</span>这样可以得到:

<span class="LaTex" alt="LaTex">$$x^nF(\dfrac{1}{x})=x^{n-m}Q(\dfrac{1}{x})*x^mG(\dfrac{1}{x})+x^{n-m+1}*x^{m-1}R(\dfrac{1}{x})$$</span>

于是:

<span class="LaTex" alt="LaTex">$$F_R(x)=Q_R(x)*G_R(x)+x^{n-m+1}*R_R(x)$$</span>

这下终于能用同余式来表示原式子了,并且未知多项式还能够少掉一个:

<span class="LaTex" alt="LaTex">$$F_R(x)\equiv Q_R(x)*G_R(x)\ (mod\ x^{n-m+1})$$</span>

那么:

<span class="LaTex" alt="LaTex">$$Q_R(x)\equiv F_R(x)*G_R^{^{-1}}(x)\ (mod\ x^{n-m+1})$$</span>

这下只要求出多项式<span class="LaTex" alt="LaTex">$$G_R(x)$$</span>的逆然后乘法就得到了<span class="LaTex" alt="LaTex">$$Q_R(x)$$</span>,翻转回去就可以进一步通过多项式乘法得到<span class="LaTex" alt="LaTex">$$R(x)$$</span>

主体代码:

```cpp
int D[N];
void Poly_divide(int *A,int *B,int n,int m){
	reverse(A,A+1+n);reverse(B,B+1+m);
	Poly_inv(B,C,D,n-m+1);
	Set(D,0);for(int i=0;i<=n-m;++i) D[i]=A[i];
	int r=(n-m)<<1,len,up;
	for(len=1,up=-1;len<=r;len<<=1,++up);
	for(int i=1;i<len;++i) rader[i]=(rader[i>>1]>>1)|((i&1)<<up);
	NTT(C,len,1);NTT(D,len,1);
	for(int i=0;i<len;++i) C[i]=1ll*C[i]*D[i]%mod;
	NTT(C,len,-1);for(int i=n-m+1;i<len;++i) C[i]=0;
	reverse(A,A+1+n);reverse(B,B+1+m);reverse(C,C+1+n-m);
	for(int i=0;i<=n-m;++i) printf("%d ",C[i]);
	puts("");
	for(len=1,up=-1;len<=n;len<<=1,++up);
	for(int i=1;i<len;++i) rader[i]=(rader[i>>1]>>1)|((i&1)<<up);
	NTT(C,len,1);NTT(B,len,1);
	for(int i=0;i<len;++i) C[i]=1ll*C[i]*B[i]%mod;
	NTT(C,len,-1);
	for(int i=0;i<m;++i) Mod(C[i]=A[i]-C[i]),printf("%d ",C[i]);
	puts("");
}
```

### 3.多项式求 ln

给定 <span class="LaTex" alt="LaTex">$$A(x)$$</span>,求<span class="LaTex" alt="LaTex">$$B(x)$$</span>使得

<span class="LaTex" alt="LaTex">$$B(x)\equiv ln\ A(x)\ (mod\ x^n)$$</span>

求对数函数直接两边求导就可以了:

<span class="LaTex" alt="LaTex">$$B'(x)=\frac{A(x)}{A'(x)}$$</span>

所以:

<span class="LaTex" alt="LaTex">$$B(x)=\int\frac{A(x)}{A'(x)}$$</span>

只需要会**求导,求不定积分,多项式求逆**就行了  

主体代码:

```cpp    
inline void Direv(int *A,int n){for(int i=1;i<n;++i) A[i-1]=1ll*A[i]*i%mod;A[n-1]=0;return;}
inline void Inter(int *A,int n){for(int i=n-2;~i;--i) A[i+1]=1ll*A[i]*inv[i+1]%mod;A[0]=0;return;}
inline void Poly_ln(int *A,int *B,int n){
	Poly_inv(A,B,n);Set(D,0);//D是辅助数组
	for(int i=0;i<n;++i) D[i]=A[i];
	Direv(D,n);int len,up;int m=n<<1;
	for(len=1,up=-1;len<=m;len<<=1,++up);
	for(int i=1;i<len;++i) rader[i]=(rader[i>>1]>>1)|((i&1)<<up);
	NTT(D,len,1);NTT(B,len,1);
	for(int i=0;i<len;++i) B[i]=1ll*B[i]*D[i]%mod;
	NTT(B,len,-1);for(int i=n;i<len;++i) B[i]=0;
	Inter(B,n);
	return;
}
```

### 4.多项式 exp

已知<span class="LaTex" alt="LaTex">$$A(x)$$</span>,求<span class="LaTex" alt="LaTex">$$B(x)$$</span>使得:

<span class="LaTex" alt="LaTex">$$B(x)\equiv e^{A(x)}\ (mod\ x^n)$$</span>

首先你需要学会**牛顿迭代**,这是个不断求导并迭代来求函数零点的方法。


就是要求:<span class="LaTex" alt="LaTex">$$G(F(x))\equiv 0\ (mod\ x^n)$$</span> 

假设我们已经知道了:

<span class="LaTex" alt="LaTex">$$G(F_0(x))\equiv 0\ (mod\ x^{\lceil\frac{n}{2}\rceil})$$</span>

把<span class="LaTex" alt="LaTex">$$G(F(x))$$</span>,在<span class="LaTex" alt="LaTex">$$F_0(x)$$</span>处泰勒展开:

<span class="LaTex" alt="LaTex">$$G(F(x))\equiv G(F_0(x))+\frac{G'(F_0(x))*(F(x)-F_0(x))}{1!}+\frac{G''(F_0(x))*(F(x)-F_0(x))^2}{2!}+\dots\ (mod\ x^n)$$</span>

我们易知<span class="LaTex" alt="LaTex">$$F(x)-F_0(x)$$</span>的低于<span class="LaTex" alt="LaTex">$$x^{\lceil\frac{n}{2}\rceil}$$</span>的项的系数为0,而我们的运算在模<span class="LaTex" alt="LaTex">$$x^n$$</span>意义下进行,那么大于等于2次的展开项都可以直接视作0,因为<span class="LaTex" alt="LaTex">$$(x^{\lceil\frac{n}{2}\rceil})^2\geq x^n$$</span>  

于是:

<span class="LaTex" alt="LaTex">$$G(F(x))\equiv G(F_0(x))+G'(F_0(x))*(F(x)-F_0(x))\ (mod\ x^n)$$</span>

而<span class="LaTex" alt="LaTex">$$G(F(x))\equiv 0\ (mod\ x^n)$$</span>,故可得:

<span class="LaTex" alt="LaTex">$$F(x)\equiv F_0(x)-\frac{G(F_0(x))}{G'(F_0(x))}\ (mod\ x^n)$$</span>

回到多项式 <span class="LaTex" alt="LaTex">$$exp$$</span>,两边取<span class="LaTex" alt="LaTex">$$ln$$</span>后可得:

<span class="LaTex" alt="LaTex">$$ln\ B(x)-A(x)\equiv 0\ (mod\ x^n)$$</span>

直接把 <span class="LaTex" alt="LaTex">$$F(x)=B(x),G(F(x))=ln\ B(x)-A(x)$$</span>代入牛顿迭代公式:

<span class="LaTex" alt="LaTex">$$B(x)\equiv B_0(x)-\frac{ln\ B_0(x)-A(x)}{\frac{1}{B_0(x)}}\ (mod\ x^n)$$</span>

可得:

<span class="LaTex" alt="LaTex">$$B(x)\equiv B_0(x)(1-ln\ B_0(x)+A(x))\ (mod\ x^n)$$</span>

倍增求出这个东西,需要 多项式求<span class="LaTex" alt="LaTex">$$ln$$</span> 的所有内容(注意求ln的数组要清空)

主体代码:

```cpp
void Poly_exp(int *A,int *B,int n){
	if(n==1) return (void)(B[0]=1);
	Poly_exp(A,B,(n+1)>>1);Poly_ln(B,C,n);
	int m=n<<1,len,up;
	for(len=1,up=-1;len<=m;len<<=1,++up);
	for(int i=1;i<len;++i) rader[i]=(rader[i>>1]>>1)|((i&1)<<up);
	for(int i=0;i<n;++i) Mod(C[i]=A[i]-C[i]);for(int i=n;i<len;++i) C[i]=0;
	Mod(++C[0]);
	NTT(C,len,1);NTT(B,len,1);
	for(int i=0;i<len;++i) B[i]=1ll*B[i]*C[i]%mod;
	NTT(B,len,-1);
	for(int i=n;i<len;++i) B[i]=0;
	return;
}
```

<span class="LaTex" alt="LaTex">$$P.S.$$</span>: **一个常错点,当运算在 <span class="LaTex" alt="LaTex">$$mod\; x^n$$</span> 下进行时,一定不能合并点值相乘的步骤,必须一次次来,并把多余的项赋成0**

### 5.多项式多点求值

求解多项式 <span class="LaTex" alt="LaTex">$$F(x)$$</span> 在 <span class="LaTex" alt="LaTex">$$x_1,x_2,x_3\dots x_m$$</span> 处的点值

预备知识:  

**余式定理:**  

一个多项式函数 <span class="LaTex" alt="LaTex">$$F(x)$$</span> 在 <span class="LaTex" alt="LaTex">$$x_0$$</span> 处的点值是 <span class="LaTex" alt="LaTex">$$F(x)\mod (x-x_0)$$</span>  

根据多项式取模的原理，因为除式是一个一次时，那么结果只有常数项。

理解可以从我们奥数中学习过的因式定理出发(尽管因式定理是余式定理的一种特殊情况)。  

因式定理指出，一个多项式<span class="LaTex" alt="LaTex">$$F(x)$$</span> 含有因式 <span class="LaTex" alt="LaTex">$$(x-x_0)$$</span> 当且仅当<span class="LaTex" alt="LaTex">$$F(x_0)=0$$</span>，这与我们因式分解法解方程的根是一样的原理。  

那么我们可以知道 <span class="LaTex" alt="LaTex">$$F(x)\mod (x-x_0)=0$$</span>，令<span class="LaTex" alt="LaTex">$$G(x)=F(x)+y_0$$</span>，由于只是增加了一个常数项，我们可以得到:  

<span class="LaTex" alt="LaTex">$$G(x_0)=F(x_0)+y_0=y_0$$</span>  
<br/>
<span class="LaTex" alt="LaTex">$$G(x)\mod (x-x_0)=(F(x)+y_0)\mod (x-x_0)=F(x)\mod (x-x_0)+y_0=y_0$$</span>

故余式定理成立。

接下来就是多点求值的方法了。

我们知道 <span class="LaTex" alt="LaTex">$$F(x) \mod (x-x_1)=F(x) \mod (x-x_1)(x-x_2) \mod (x-x_1)$$</span>，因为之后取模的多项式是上次取模的多项式的一个因式，显然结果不受上次取模的影响。

这样我们可以发现多项式的次数可以降低而不影响最终的点值。  

那么我们定义 <span class="LaTex" alt="LaTex">$$P_{l,r}(x)=\prod_{i=l}^r (x-x_i)$$</span>  

然后考虑分治求解点值。按照线段树那样dfs。  

对于当前多项式 <span class="LaTex" alt="LaTex">$$F_{l,r}(x)$$</span>。  

往左走就令 <span class="LaTex" alt="LaTex">$$F_{l,mid}(x)=F_{l,r}(x)\mod P_{l,mid}(x)$$</span>  

往右走就是 <span class="LaTex" alt="LaTex">$$F_{mid+1,r}(x)=F_{l,r}(x)\mod P_{mid+1,r}(x)$$</span>  

这样每次往下走一步多项式的长度都减半,次数之和就是 <span class="LaTex" alt="LaTex">$$O(nlogn)$$</span> ，总体复杂度就是<span class="LaTex" alt="LaTex">$$O(nlog^2n)$$</span>  

当然中间的常数巨大...

这样我们先用 分治+多项式乘法 来求出每一个线段树上节点的 <span class="LaTex" alt="LaTex">$$P(x)$$</span>， 然后递归分治进取求解点值，到了最底下的点值就是其 <span class="LaTex" alt="LaTex">$$F(x)$$</span>的常数项了。

为了卡常可以当当前区间长度较小的话改用暴力直接计算点值。

主体code:

```cpp
#define ls (u<<1)
#define rs (u<<1|1)
int POOL[MAXM],cnt=0;
int *P[MAXN],*F[MAXN],X[N];int ans[N];

inline int* Neospace(int len){int*ret=&POOL[cnt];cnt+=len;return ret;}
inline int Calc(int*F,int n,const int x){int X=1,ret=0;for(int i=0;i<n;++i) Inc(ret,(ll)F[i]*X%mod),X=(ll)X*x%mod;return ret;}

inline void Divide(int u,int l,int r){P[u]=NULL;
	if(l==r) {P[u]=Neospace(2);P[u][0]=mod-X[l];P[u][1]=1;return;}
	static int L[MAXN],R[MAXN];int mid=(l+r)>>1;int LS=ls,RS=rs;
	Divide(LS,l,mid);Divide(RS,mid+1,r);
	int n=r-l+2,nl=mid-l+2,nr=r-mid+1;
	for(int i=0;i<nl;++i) L[i]=P[LS][i];
	for(int i=0;i<nr;++i) R[i]=P[RS][i];
	Mul(L,R,L,nl,nr);P[u]=Neospace(n);
	for(int i=0;i<n;++i) P[u][i]=L[i];
	return;
}

inline void Poly_Evaluation(int u,int l,int r){//注意最开始的多项式也要取一次模
	if(r-l+1<=200) {for(int i=l;i<=r;++i) ans[i]=Calc(F[u],r-l+1,X[i]);return;}// 长度小的暴力计算
	int mid=(l+r)>>1,LS=ls,RS=rs;
	int n=r-l+1,nl=mid-l+1,nr=r-mid;
	static int R[MAXN];
	F[LS]=Neospace(nl),F[RS]=Neospace(nr);
	Poly_Mod(F[u],P[LS],__,R,n-1,nl);
	for(int i=0;i<nl;++i) F[LS][i]=R[i];
	Poly_Mod(F[u],P[RS],__,R,n-1,nr);
	for(int i=0;i<nr;++i) F[RS][i]=R[i];
	Poly_Evaluation(LS,l,mid);
	Poly_Evaluation(RS,mid+1,r);
	return;
}

void Solve(){
	int n,m;init(n),init(m);++n,++m;
	static int A[MAXN];
	for(int i=0;i<n;++i) init(A[i]);
	Input_Array(X,1,m);Divide(1,1,m-1);
	F[1]=Neospace(m-1);
	Poly_Mod(A,P[1],__,F[1],n-1,m-1);
	Poly_Evaluation(1,1,m-1);
	for(int i=1;i<m;++i) printf("%d\n",ans[i]);
}
```

### 6.多项式快速插值

问题:  

给定 <span class="LaTex" alt="LaTex">$$n$$</span> 个点 <span class="LaTex" alt="LaTex">$$(x_i,y_i)$$</span> ，求出这些点确定的一个 <span class="LaTex" alt="LaTex">$$n-1$$</span> 次多项式。

前置知识:  

拉格朗日插值与多项式多点求值。

考虑拉格朗日插值:

<span class="LaTex" alt="LaTex">$$F(x)=\sum_{i=1}^ny_i\prod_{j\neq i}\frac{x-x_j}{x_i-x_j}$$</span>

复杂度是 <span class="LaTex" alt="LaTex">$$O(n^2)$$</span>  

考虑快速计算后面这一部分。  

我们定义 <span class="LaTex" alt="LaTex">$$\pi(x)=\prod_{i=1}^n(x-x_i)$$</span>，把式子变形一下就是:

<span class="LaTex" alt="LaTex">$$F(x)=\sum_{i=1}^n\frac{y_i}{\dfrac{\pi(x_i)}{x_i-x_i}}*\frac{\pi(x)}{x-x_i}$$</span>

显然第一个东西下面的分式是一个 <span class="LaTex" alt="LaTex">$$\frac{0}{0}$$</span> 的形式，因为 <span class="LaTex" alt="LaTex">$$x\rightarrow x_i时,(x-x_i)\rightarrow 0 , \pi(x)\rightarrow 0$$</span>

根据洛必达法则求函数极限: <span class="LaTex" alt="LaTex">$$\lim_{x\rightarrow x_i}\frac{\pi(x)}{(x-x_i)}=\lim_{x\rightarrow x_i} \frac{\pi'(x)}{(x-x_i)'}$$</span>

因为 <span class="LaTex" alt="LaTex">$$(x-x_i)'=1,$$</span>所以结果就是 <span class="LaTex" alt="LaTex">$$\pi'(x_i)$$</span>  

那么原式就变成了:

<span class="LaTex" alt="LaTex">$$F(x)=\sum_{i=1}^n\frac{y_i}{\pi'(x_i)}*\frac{\pi(x)}{x-x_i}$$</span>

前面的那部分就可以直接多点求值先全部算出来了。

然后就是处理后面的部分了，这个东西也可以类似分治的求。  

设 <span class="LaTex" alt="LaTex">$$F_{l,r}(x)$$</span> 表示 <span class="LaTex" alt="LaTex">$$[l,r]$$</span> 内的点插值出来的多项式，那么这个东西可以由左右两边合并得到，具体来说是:

<span class="LaTex" alt="LaTex">$$F_{l,r}(x)=F_{l,mid}(x)*\pi_{mid+1,r}(x)+F_{mid+1,r}(x)*\pi_{l,mid}(x)$$</span>

推导略。

主体code:

```cpp    
inline void Poly_Interpolate(int u,int l,int r){// 多项式快速插值
	if(l==r) {G[u]=Neospace(1);G[u][0]=val[l];return;}
	int mid=(l+r)>>1,LS=ls,RS=rs,n=r-l+1,nl=mid-l+1,nr=r-mid;
	Poly_Interpolate(LS,l,mid);
	Poly_Interpolate(RS,mid+1,r);
	static int L[MAXN],R[MAXN];
	G[u]=Neospace(n);
	Mul(G[LS],P[RS],L,nl,nr+1);
	Mul(G[RS],P[LS],R,nr,nl+1);
	for(int i=0;i<n;++i) G[u][i]=Sum(L[i],R[i]);
	return;
}

inline void Solve_Interpolation(int*_X,int*Y,int*ans,int n){
	cnt=0;for(int i=1;i<=n;++i) X[i]=_X[i];
	Divide(1,1,n);static int Val[N];val=Val;int hcnt=cnt;
	F[1]=Neospace(n);for(int i=0;i<=n;++i) F[1][i]=P[1][i];
	Direv(F[1],n+1);Poly_Evaluate(1,1,n);
	Clear(POOL,hcnt,cnt);cnt=hcnt;
	for(int i=1;i<=n;++i) Val[i]=(ll)Y[i]*fpow(Val[i],mod-2)%mod;
	Poly_Interpolate(1,1,n);for(int i=0;i<n;++i) ans[i]=G[1][i];
	return;
}
```

## 4.FWT(快速沃尔什变换)

### 1.概述

我们知道假设有两个多项式 <span class="LaTex" alt="LaTex">$$A,B$$</span>,他们的多项式卷积可以写成以下形式(中间打个乘号的话表示的是按位相乘,没有则为卷积)

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j+k=i} A_j*B_kx^i$$</span>

但假设现在有一个问题是给你两堆集合,求出在两堆中各选出一个集合使得他们的并集是某个集合的方案数

这个问题其实就是要求出以下形式的卷积:

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j|k=i} A_j*B_kx^i$$</span>

<span class="LaTex" alt="LaTex">$$x^i$$</span>的系数即为集合为<span class="LaTex" alt="LaTex">$$i$$</span>时的答案

所以<span class="LaTex" alt="LaTex">$$FWT$$</span>就是把普通多项式乘法卷积中的<span class="LaTex" alt="LaTex">$$j+k=i$$</span>变成了<span class="LaTex" alt="LaTex">$$j\oplus k=i$$</span>,其中<span class="LaTex" alt="LaTex">$$\oplus$$</span>表示一个位运算的算法,也就是:

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j\oplus k=i} A_j*B_kx^i$$</span>

现在就要找到一种方法能够快速求出以上卷积。

仿照<span class="LaTex" alt="LaTex">$$FFT$$</span>的方法,我们希望找到一种变换<span class="LaTex" alt="LaTex">$$FWT$$</span>,能够使得:

<span class="LaTex" alt="LaTex">$$FWT(C=A\ B)=FWT(A)*FWT(B)$$</span>

以上操作类似于<span class="LaTex" alt="LaTex">$$FFT$$</span>点值相乘,复杂度为O(n),这样的化我们通过找到一种<span class="LaTex" alt="LaTex">$$FWT$$</span>的逆变换<span class="LaTex" alt="LaTex">$$IFWT$$</span>就可以还原出结果多项式了  

复杂度就在于求出 <span class="LaTex" alt="LaTex">$$FWT$$</span>

一下开始讲三种位运算的卷积,注意之后的下标可以将其理解为一个集合

### 2.或卷积

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j|k=i} A_j*B_kx^i$$</span>

由于<span class="LaTex" alt="LaTex">$$j|k=i$$</span> ,显然的 <span class="LaTex" alt="LaTex">$$i\subseteq j$$</span>且<span class="LaTex" alt="LaTex">$$k\subseteq i$$</span>

通过分析(xia cai),我们感觉可以构造这样的<span class="LaTex" alt="LaTex">$$FWT$$</span>形式(<span class="LaTex" alt="LaTex">$$FWT(A)_i$$</span>表示多项式<span class="LaTex" alt="LaTex">$$A$$</span>经过变换后的第<span class="LaTex" alt="LaTex">$$i$$</span>项):

<span class="LaTex" alt="LaTex">$$FWT(A)_i=\sum_{j\subseteq i(j|i=i)}A_i$$</span>

这样对于 <span class="LaTex" alt="LaTex">$$C_i=\sum_{j|k=i}A_j*B_k$$</span>,可得:

<span class="LaTex" alt="LaTex">$$FWT(C)_i=\sum_{j\subseteq i}C_i=\sum_{j\subseteq i}\sum_{p|q=j} A_p*B_q$$</span>

我们可以发现对于任意一对 <span class="LaTex" alt="LaTex">$$p,q$$</span>,当且仅当<span class="LaTex" alt="LaTex">$$j$$</span>枚举到 <span class="LaTex" alt="LaTex">$$p|q$$</span>时会被计算一次贡献,而我们显然有<span class="LaTex" alt="LaTex">$$p\subseteq j$$</span>,<span class="LaTex" alt="LaTex">$$q\subseteq j$$</span>,因此式子可以改写为:

<span class="LaTex" alt="LaTex">$$FWT(C)_i=\sum_{p\subseteq i}\sum_{q\subseteq i} A_p*B_q$$</span>

显然可以用分配率提出来<span class="LaTex" alt="LaTex">$$A_p$$</span>

<span class="LaTex" alt="LaTex">$$FWT(C)_i=\sum_{p\subseteq i}A_p\sum_{q\subseteq i} B_q=FWT(A)_i*FWT(B)_i$$</span>

万事大吉,这样就找到一种优秀的<span class="LaTex" alt="LaTex">$$FWT$$</span>形式了

剩下的就是看怎么快速求出这个<span class="LaTex" alt="LaTex">$$FWT$$</span>和<span class="LaTex" alt="LaTex">$$IFWT$$</span>了

如果你去看很多其他人的博客,他们会通过分治思想,多项式拼接什么的把非巨佬以外的人绕的云里雾里,然后再甩给你一个代码。  

但是你没发现或运算下的<span class="LaTex" alt="LaTex">$$FWT$$</span>就是个子集的前缀和吗,所以直接用高维前缀和求就行了。  

对,就是这段代码:

```cpp    
for(int i=0;i<m;++i)
	for(int j=0;j<n;++j){if(j>>i&1) Inc(A[j],A[j^bin[i]]);}
```

<span class="LaTex" alt="LaTex">$$FWT$$</span>的精髓在于构造优秀的变换形式,求解变换就是高维前缀和。

至于为什么可以写成和<span class="LaTex" alt="LaTex">$$FFT$$</span>代码高度相似,是因为那个是直接枚举已经确定下来的<span class="LaTex" alt="LaTex">$$1$$</span>左右两边的0/1情况,理论上能少一半的常数,但是会多一重循环(说不定常数更大了),也就是长成这样:

```cpp
for(int i=1;i<n;i<<=1)
	for(int p=i<<1,j=0;j<n;j+=p)
		for(int k=0;k<i;++k) f? Inc(A[j|k|i],A[j|k]):Dec(A[j|k|i],A[j|k]);//这是模意义下加减法
```

后面那个减法就是 <span class="LaTex" alt="LaTex">$$IFWT$$</span>了,就是把高位前缀和的操作反着来一边就行了,把子集的和减去就得到原本自己的值

这就是或卷积了。

### 3.与卷积

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j\&k=i} A_j*B_kx^i$$</span>

与和或运算非常相似,所以找<span class="LaTex" alt="LaTex">$$FWT$$</span>的思想一样,直接把子集前缀和换成超集前缀和就行了:

<span class="LaTex" alt="LaTex">$$FWT(A)_i=\sum_{i\subseteq j(j\&i=i)}A_i$$</span>

后面的推导是一样的,求解<span class="LaTex" alt="LaTex">$$FWT$$</span>也一样高位前缀和解决,代码如下:

```cpp  
for(int i=1;i<n;i<<=1) 
	for(int p=i<<1,j=0;j<n;j+=p) 
		for(int k=0;k<i;++k) f? Inc(A[j|k],A[j|k|i]):Dec(A[j|k],A[j|k|i]);
```

仅仅只是把操作的对应数组下标前后交换了一下,其他一模一样

### 4.异或卷积

用<span class="LaTex" alt="LaTex">$$\oplus$$</span>表示异或

<span class="LaTex" alt="LaTex">$$A(x)\ B(x)=\sum_{i=0}^{\infty}\sum_{j\oplus k=i} A_j*B_kx^i$$</span>

异或的话要自己瞎找就有点难了只能直接放结论了:

<span class="LaTex" alt="LaTex">$$FWT(A)_i=\sum_{(i\&j)\&1=0}A_j-\sum_{(i\&j)\&1=1}A_j$$</span>

不过这个代码写起来就真的可以和<span class="LaTex" alt="LaTex">$$FFT$$</span>一模一样了,代码:

```cpp  
for(int i=1;i<n;i<<=1)
	for(int p=i<<1,j=0;j<n;j+=p)
		for(int k=0;k<i;++k){
			int X=A[j|k],Y=A[j|k|i];
			Mod(A[j|k]=X+Y);Mod(A[j|k|i]=X-Y);
			if(!f) A[j|k]=1ll*A[j|k]*inv%mod,A[j|k|i]=1ll*A[j|k|i]*inv%mod;//inv是2的逆元,不是模意义下就直接除以2
		}
```
